## Compilation & Execution Instructions

### Prerequisites

**C++ Compiler:** g++ with C++17 support standard.

**Shell Environment:** Terminal (Bash/Zsh) or PowerShell.

### Compiling the Source Code

To compile the main source code using g++:

```bash
g++ -std=c++17 Assignment01_Buitano.cpp -o assignment01
./assignment01
```
