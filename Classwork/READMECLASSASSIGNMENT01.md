## How to Run
Open a terminal in this folder and run:

```
g++ -std=c++17 -o p1 Assignment01_Problem01_Buitano.cpp && ./p1
```

Change `p1` and `01` to run the other problems (`p2` / `02`, etc.).

No input is needed. Each program uses the array A = {34, 7, 23, 32, 5, 62, 14, 19}.
